# Hermes Linux runtime maintenance

Use for Dashboard/Web UI/Gateway memory pressure, stale TUI/MCP children, DNS instability, SQLite WAL-reset warnings, and swap recovery.

1. Measure each systemd user unit with `MemoryCurrent`, `MemorySwapCurrent`, `TasksCurrent`, its cgroup path, and recursive `cgroup.procs` counts. Sample every 60 seconds with a user timer.
2. Treat Dashboard TUI sessions as process groups. Preserve the current TUI session; terminate only positively identified stale `tui_gateway.slash_worker` process groups. Its MCP watchdog descendants should exit with it. A manually killed child can remain as a zero-memory zombie until its Python parent calls `waitpid`; a controlled parent restart or one explicit parent-side reap clears it.
3. Rotate `~/.hermes/logs/mcp-stderr.log` by size with `copytruncate` semantics because long-lived MCP processes retain open file descriptors. Keep bounded compressed generations.
4. Classify Gateway `ExecStopPost` using systemd `$SERVICE_RESULT`, `$EXIT_CODE`, `$EXIT_STATUS`, and `$INVOCATION_ID`: exit 75 = `planned_tempfail`; `oom-kill`/SIGKILL = `oom`; killed/dumped or a current-invocation `Shutdown context: signal=` line = `signal`; remaining non-success = `failure`.
5. Validate public DNS answers against an encrypted reference before adding plain UDP resolvers. This network transparently redirected several public DNS IPs. Stable shape: dnscrypt-proxy on `127.0.2.1` with Cloudflare + Quad9 encrypted upstreams, router DNS `10.0.0.2` as second system resolver, and a 60-second direct-resolver probe.
6. Hermes uv Python can embed a vulnerable SQLite independently of the OS package. Keep the official checkout and venv pristine. This host uses `/opt/ai/hermes-sqlite-runtime`: `ensure-runtime` builds an ABI-specific `pysqlite3` against SQLite 3.53.3, validates FTS5 and rpath resolution, then atomically switches `current`. `~/.local/bin/hermes` and systemd `40-sqlite-runtime.conf` activate it. Use `/opt/ai/hermes-runtime-compat/bin/hermes-official-update` for backed-up official updates, detached three-service restart, and full post-update verification. The overlay ignores child interpreters with a different Python ABI.
7. Recycle swap only after stale-process cleanup and only when `MemAvailable - SwapUsed` leaves a safe margin. Capture `vmstat` before/after. Preserve the host's existing `vm.swappiness=1`. Short `so` bursts after swapoff/swapon are expected under memory pressure; verify they stop and watch sustained `si`.
8. Use `busctl --user ... Manager RestartUnit` from a Hermes child when the terminal safety guard correctly blocks a direct Gateway restart.
